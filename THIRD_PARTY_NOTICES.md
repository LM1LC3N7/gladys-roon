## node-roon-api (RoonLabs/node-roon-api)

<https://github.com/RoonLabs/node-roon-api>, Copyright Roon Labs, LLC, the
official JavaScript library of the Roon extension API, version 1.2.3 (`master`
at commit 055dae6c2ac45b6c738aa3b9e5ac1fd722ed60e8, 2026-02-03). Apache
License 2.0.

Ported in `src/roon/moo.js` (the MOO/1 message format of `moo.js` and
`moomsg.js`), `src/roon/session.js` (the connection logic of `lib.js` and
`transport-websocket.js`: `registry/info`, `registry/register` with the
token kept by core id, the ping and status services, the WebSocket keepalive)
and `src/roon/sood.js` (the SOOD discovery message of `sood.js`). Changed
here: no file `config.json` in the working directory (the token is kept in
/data by the app), no console logging (the library logs every body, the
token included), no discovery sockets (the query goes through the Gladys
core), header lines, lengths and bodies checked and bounded, one session at a
time.

Why a port rather than a dependency: the library is not published on npm (a
git dependency would need git in the image), it depends on `node-uuid`
(deprecated), and its logging and file config do not fit a read-only
container. The WebSocket itself is `ws` (MIT), the library's own transport.

## node-roon-api-transport and node-roon-api-image (RoonLabs)

<https://github.com/RoonLabs/node-roon-api-transport> (version 2.0.1, commit
2ee60008a4cdb90c34ff3de58bb4b949067f1d20) and
<https://github.com/RoonLabs/node-roon-api-image> (commit
a5f0efaf2dfb5457e91abe326c3a40d865131d32), Copyright Roon Labs, LLC, Apache
License 2.0: the names and bodies of the transport requests (`control`,
`change_volume`, `mute`, `seek`, `change_settings`, `group_outputs`,
`ungroup_outputs`, `subscribe_zones`, `subscribe_outputs`), the fields of a
zone and an output, the `get_image` request. Facts of an interface, read in
`src/roon/model.js`, `src/roon/session.js` and `src/app.js`.

## Home Assistant, roon integration (home-assistant/core)

<https://github.com/home-assistant/core/tree/dev/homeassistant/components/roon>,
Apache License 2.0: read as documentation. Two choices follow it: one device
per output (not per zone), identified by the output display name (Home
Assistant saw output and zone ids change), and the volume read as a percent
of the range of the output. No code ported; its extension id is not used.
